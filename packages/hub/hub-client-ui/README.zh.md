# dsh-hub-client-ui

[English](README.md) | 中文

`@k1412/dsh-hub-client-ui` 是装入官方 DSH Web 的 Hub 专用客户端插件。它在官方新建会话行中贡献节点／Runtime 选择器，并在官方设置框架中增加管理页面。它不替换会话、项目、消息、模型选择、文件夹选择或交互流程，也不从节点加载前端 JavaScript。

## 页面

- **新会话目标**：在官方 Workspace picker 旁列出在线且声明 `dsh.web.fetch` 的 Runtime；上次选择会自动预选，切换目标只清除当前空白会话选择，选择汇总列表中的已有 Workspace 时则会自动同步到其所属节点。
- **当前 Runtime**：在官方设置标题栏中显示当前节点和 Runtime。切换时只更新当前标签页的所有者，同时刷新 Schema Scope 与模型、权限、Agent 等直接 Host 控制器，不再重新挂载官方设置外壳；代次隔离会阻止上一个节点的延迟响应被显示或写入。语言和外观仍属于浏览器，Hub 节点属于 Hub 全局，节点插件页则单独选择管理目标。
- **Hub 节点**：创建一次性注册授权、查看和取消待接入节点、查看在线状态与 Runtime、监控节点到 Hub 与 Hub 到节点的可靠队列、Stream 中断、正在等待的浏览器控制请求和命令超时，为没有既有所有者的操作选择默认 Runtime（不会过滤 Fleet 会话页），并吊销节点身份。页面每 15 秒刷新一次健康数据。
- **节点插件**：显示实际安装版本、启用状态与健康状态；逐项区分 npm、外部管理和查询失败；更新前由 Node Agent 自动保存依赖与 Cordis 状态；显示每次更新结果并提供一键回退。
- **高级诊断**：默认折叠在 Hub 节点页。终端是 Node Agent 账号权限下的应急 Shell；文件工具只从操作员输入的绝对路径开始，写入和删除使用内容哈希阻止覆盖并发变更。它们不是日常聊天或项目文件浏览入口。
- **受管范围快照**：默认折叠在节点插件页，与插件自动回退分离。它只用于显式配置、依赖或获准数据目录恢复点，不是操作系统整机镜像。

所有变更调用同源 Hub API。Cloudflare Access 认证、Hub 操作员白名单、Origin Secret 和节点能力校验由服务端执行；浏览器从不持有节点 Service Token 或节点私钥。经过审查的 Hub HTML 会显式允许通过这条认证控制面使用 Host 持久设置，但不会把公网页面标记为 Loopback，因此“在本机打开路径”等桌面原生动作在远程仍不可用。

## 模型体验

无，因为新会话选择器和设置页都不注册面向模型的工具或上下文。

#### KV Cache 影响

无；设置页状态不会进入模型请求。

## 已知限制与后续工作

- 终端保留 256 KiB 浏览器 Scrollback，关闭页面会关闭 PTY；它不是可恢复会话。
- 文件编辑器只允许完整读取的不超过 1 MiB 的 UTF-8 普通文件。二进制或更大文件只显示安全说明，不允许在浏览器中保存。
- 选中的 Runtime 是设置与无既有所有者操作的归属方，不是 Fleet 列表过滤器。所有已注册节点的会话仍会汇总显示，按 Workspace 文件夹分组并附带节点标签。
