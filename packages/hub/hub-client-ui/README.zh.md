# dsh-hub-client-ui

[English](README.md) | 中文

`@k1412/dsh-hub-client-ui` 是装入官方 DSH Web 设置框架的 Hub 专用客户端插件。它不替换会话、项目、消息、模型选择或交互流程，也不从节点加载前端 JavaScript。

## 页面

- **Hub 节点**：创建一次性注册授权、查看和取消待接入节点、查看在线状态与 Runtime、切换当前 Runtime、吊销节点身份。
- **节点插件**：显示实际安装版本、启用状态与健康状态；检查 npm 更新；更新前由 Node Agent 自动保存依赖与 Cordis 状态；显示每次更新结果并提供一键回退。
- **高级诊断**：默认折叠在 Hub 节点页。终端是 Node Agent 账号权限下的应急 Shell；文件工具只从操作员输入的绝对路径开始，写入和删除使用内容哈希阻止覆盖并发变更。它们不是日常聊天或项目文件浏览入口。
- **整机快照**：默认折叠在节点插件页，与插件自动回退分离。它只用于显式配置、依赖或获准数据目录恢复点。

所有变更调用同源 Hub API。Cloudflare Access 认证、Hub 操作员白名单、Origin Secret 和节点能力校验由服务端执行；浏览器从不持有节点 Service Token 或节点私钥。

## 模型体验

无，因为本包只扩展操作员设置界面，不注册面向模型的工具或上下文。

#### KV Cache 影响

无；设置页状态不会进入模型请求。

## 已知限制与后续工作

- 终端保留 256 KiB 浏览器 Scrollback，关闭页面会关闭 PTY；它不是可恢复会话。
- 文件编辑器只允许完整读取的不超过 1 MiB 的 UTF-8 普通文件。二进制或更大文件只显示安全说明，不允许在浏览器中保存。
